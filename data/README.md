# Google Play Store Machine Learning Project

## Project Overview
This project analyzes Google Play Store applications and uses Machine Learning algorithms to predict application ratings.

## Objectives
- Analyze Google Play Store applications.
- Clean and preprocess the dataset.
- Perform Exploratory Data Analysis (EDA).
- Identify important features.
- Build Machine Learning models.
- Evaluate and compare model performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithms
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Model Evaluation

Optimized Random Forest results:

| Metric | Score |
|---|---:|
| MAE | 0.3242 |
| RMSE | 0.4743 |
| R2 Score | 0.1450 |
| Cross Validation R2 | 0.1641 |

## Project Structure
- data: Original and processed datasets and model files.
- notebooks: Jupyter Notebook containing the complete project.
